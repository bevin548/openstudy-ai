# OpenStudy AI

An open-source AI study assistant designed to help students learn more effectively.

## Features

- Summarize study notes
- Generate practice questions
- Explain difficult topics
- Create personalized study plans
- Open-source and free to improve

## Goal

OpenStudy AI aims to make AI-powered learning assistance accessible to students while keeping the project open-source and community-driven.

## Project Status

🚧 Early development

The project is currently being developed and new features will be added over time.
